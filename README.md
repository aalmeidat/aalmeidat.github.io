# aalmeidat.github.io

Source of [aalmeidat.github.io](https://aalmeidat.github.io), the academic homepage of Andres Almeida (University of Virginia).

Built with Jekyll from the [AcademicPages](https://github.com/academicpages/academicpages.github.io) template (MIT license, see `LICENSE`) and deployed to GitHub Pages by the workflow in `.github/workflows/jekyll.yml`.

- Pages: `_pages/` (About, Research, Publications, Talks, Survey operations, CV)
- Top bar: `_data/navigation.yml`; sidebar and site settings: `_config.yml`
- CV PDF: `files/AlmeidaToro_CV.pdf`; images: `images/`

Interactive data pages live in their own repositories and are served under this domain, for example
[aalmeidat.github.io/magellanic-joker-orbits](https://aalmeidat.github.io/magellanic-joker-orbits/).
